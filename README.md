# 125A Fruity SoundFont Player – Compatibility Research

Windows x64 VST3 research aiming to make the original 32-bit Fruity SoundFont Player engine usable without FL Studio.

**Status: research, NOT a working VST3.** The available legacy files are proprietary and their provenance/licensing is not established. They must never be committed to this public repository. No crack, activation bypass or redistribution is part of this project.

Development is kept on branches, not `main`. Follow [125A Engineering START-HERE](https://github.com/challanger2000/125A-Engineering/blob/main/START-HERE.md) before implementation.
